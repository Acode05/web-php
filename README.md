# PetStore-Website
- Pawsy – Pet Store Website

A web-based pet store developed as a university project for the Information Technology program.

The project provides an online platform where users can browse pet products, create accounts, and interact with the website through a secure PHP and MySQL backend.


- Overview

Pawsy is designed to simulate a real e-commerce website for pet supplies. The system focuses on providing a simple and user-friendly shopping experience while demonstrating full-stack web development concepts.



- Features

- User Registration & Login
- Browse Products
- Product Details
- Shopping Cart
- Database Integration
- Responsive Design
- CRUD Operations


- Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- XAMPP
